# Каталог настольных игр

Консольная программа для просмотра настольных игр и поиска по жанру.

## Возможности

- выводит список игр;
- показывает жанр и количество игроков;
- фильтрует игры по выбранному жанру;
- сообщает, если подходящих игр нет.

## Структура проекта

| Файл | Назначение |
|---|---|
| main.py | Запускает программу |
| games.py | Содержит функции каталога и фильтрации |

## Запуск

```bash
python main.py
```
